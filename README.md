# Meridian Trust Bank QBR

An interactive presentation website prepared by Jason Benson for the Hummingbird Customer Success interview exercise. Content follows the current Meridian Trust Bank presentation.

## Run locally

`python3 -m http.server 4173`

Open `http://localhost:4173`.

This is a static HTML, CSS and JavaScript site. No install or build step is required. Deploy the repository root with the Vercel “Other” framework preset.

## Editing

- `index.html`: the five chapter narrative and initial content.
- `app.js`: priority, recovery, adoption, pilot and monthly plan interaction content.
- `model.js`: capacity calculation.
- `styles.css`: responsive layout, branding, animations and print styles.

Added operating metrics are documented as scenario assumptions in the Sources dialog and deck speaker notes. Proposed dates and targets remain identified in the narrative. Internal account strategy from the source deck is not included in the published customer presentation. The discussion checklist is browser-local; it does not record customer approval or send data anywhere.

Hummingbird artwork and wordmark are from its public website, retained for this interview exercise. Reference links are available in the page’s Sources dialog.
